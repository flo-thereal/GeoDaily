# GeoDaily

**[Play now →](https://flo-thereal.github.io/GeoDaily/)**

GeoDaily is a geography learning app — a static React SPA deployed to GitHub Pages. Daily challenges are pre-generated JSON; progress lives in your browser.

## Third-party services

The app loads flag images from [flagcdn.com](https://flagcdn.com), map tiles from [OpenStreetMap](https://www.openstreetmap.org), and fonts from Google Fonts. There is no analytics or account system.

## Prerequisites

- Node.js 20+
- npm

## Local development

```bash
npm install
npm run dev
```

The dev server uses base path `/geodaily/` by default (see [`vite.config.ts`](vite.config.ts)).

## Production (GitHub Pages)

Push to `main` — GitHub Actions builds and deploys automatically.

- **Deploy workflow:** [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)
- **Daily challenges:** [`.github/workflows/generate-challenges.yml`](.github/workflows/generate-challenges.yml) (requires `GEMINI_API_KEY` repo secret)

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup details.

## Test commands

- Unit tests: `npm run test`
- E2E tests: `npm run test:e2e`

## Daily use

See [DAILY_USE.md](DAILY_USE.md).

## Architecture

- **Frontend:** Vite + React + Zustand (persisted to localStorage)
- **Challenges:** `public/data/challenges/*.json` (generated by CI)
- **Countries:** `src/data/countries.json`
- **No backend** in production
